2.a <!-- Código controlado el día 12/08/2009 →
- Sección: Se puede colocar tanto en el <head> como en el <body>.
- Efecto: Pretende ser un comentario HTML, pero presenta un error de sintaxis al final. No se renderiza en la pantalla del navegador; 
sirve únicamente como nota explicativa o documentación para el desarrollador.
- Desglose y corrección:
  * Sintaxis correcta: <!-- Código controlado el día 12/08/2009 -->
  * Error detectado: Le falta la etiqueta/delimitador de cierre correcto (-->). Al usar '→', el comentario no se cierra correctamente y 
  el navegador considerará como parte del comentario todo el código que le siga.
- Atributos: No posee.

2.b <div id="bloque1">Contenido del bloque</div> 
-Seccion: Se coloca dentro de la seccion <body> del doc HTML, ya que es un elemento que forma parte del contenido visible de la pagina.
-Efecto: <div> crea un contenedor o bloque que contiene texto, en este caso "Contenido del bloque".
-Elementos y etiquetas: El elemento utilizado es <div>. Posee dos etiquetas: 
<div> --> etiqueta de apertura.
</div> --> etiqueta de cierre.
-Atributos: Posee un atributo con nombre: id y su valor es "bloque1".
-Obligatoriedad: El elemento <div> no es obligatorio dentro de un documento HTML.
