2.b <div id="bloque1">Contenido del bloque</div> 
-Seccion: Se coloca dentro de la seccion <body> del doc HTML, ya que es un elemento que forma parte del contenido visible de la pagina.
-Efecto: <div> crea un contenedor o bloque que contiene texto, en este caso "Contenido del bloque".

<div> --> etiqueta de apertura.

2.c <img src="" alt="lugar imagen" id="iml" name="iml" width="32" height="32" longdesc="detalles.htm"/>
-Seccion: Se coloca dentro de la seccion <body> del doc HTML, ya que es un elemento que forma parte del contenido visible de la pagina.
-Efecto: <img> permite insertar una imagen en la pagina. En este caso, 
la imagen no tiene una ubicacion especifica porque el atributo src tiene un valor vacio.
Los atributos width y height establecen un ancho y alto de 32 pixeles.
-Elementos y etiquetas: El elemento que se utiliza es <img>. Es un elemento vacio, por lo que no posee etiqueta de cierre.
Se usa la unica etiqueta: <img .../>
-Atributos: 
src --> su valor es ""y especifica la ubicacion de la imagen.
alt --> su valor es "lugar imagen" y proporciona un texto alternativo para la imagen.
id --> su valor es "iml" e identifica el elemento dentro del documento.
name --> su valor tambien es "iml" y asigna el nombre al elemento.
width --> su valor es "32" y estabece el ancho de la imagen.
height --> su valor es "32" y estabece la altura de la imagen.
longdesc --> su valor es "detalles.htm" e indica la ubicacion de una descripcion detallada de la imagen.
-Obligatoriedad: El elemento <img> no es obligatoriodentro del documento HTML. 
Los atributos src y alt son los atributos principales para especificar la imagen y su descripcion alternativa, 
mientras que id, name, width, height y longdesc son opcionales. 

2.d <meta name="keywords" lang="es" content="casa, compra, venta, alquiler"/>
<meta http-equiv="expires" content="16-Sep-2019 7:49PM"/>
-Seccion: Se colocan dentro de la seccion <head> del doc HTML, ya que son elementos que proporcionan informacion
sobre el documento y no forman parte del contenido visible de la pagina.
-Efecto: El primer elemnto <meta> proporciona informacion sobre las palabras clave asociadas al documento, en este caso
relacionadas con una casa, compra, venta y alquiler. El atributo lang nos indica que las palabras estan en español.
El segundo elemento <meta> indica una fecha y hora de expieracion del documento mediante el atributo http-equiv,
estableciento como fecha de expiracion el16 de septiembre de 2019 a las 7:49PM.
-Elementos y etiquetas: Se usan los dos elementos <meta>. Ambos son elementos vacios por lo que no tienen etiqueta de cierre.
-Atributos: 
El primer elemento <meta> tiene los atributos:
name --> su valor es "keywords" e indica que el contenido son palabras clave del documento.
lang --> su valor es "es" e indica que el contenido esta en español.
content --> contiene las palabras clave "casa, compra, venta, alquiler"

segundo elemento posee: 
http-equiv -> su valor es "expires" y eso indica que se establece una fecha de expiracion para el doc.
content-> su valor es "16-Sep-2019 7:49PM" e indica la fecha y hora de expiracion.
-Obligatoriedad: Los elementos <meta> no son obligatorios dentro de un documento HTML. Los atributos usados en 
ambos elementos son opcionales pero algunos son necesarios para indicar que informacion proporciona cada etiqueta <meta>.

2.e <a href="http://www.e-style.com.ar/resumen.html" type="text/html" hreflang="es" charset="utf-8"
rel="help">Resumen HTML </a>
-Sección: Se coloca dentro de la sección <body> del documento HTML, ya que el elemento <a> forma parte del contenido visible y 
permite crear enlaces interactivos en la página.
-Efecto: La etiqueta <a> crea un hipervínculo que, al hacer clic en el texto “Resumen HTML”, dirige al usuario al sitio web indicado 
en el atributo href. En este caso, el enlace apunta a la página http://www.e-style.com.ar/resumen.html.
-Elemento y etiqueta: Se utiliza el elemento <a> (ancla). Es un elemento que sí tiene etiqueta de cierre, por lo que se escribe como <a> ... </a>.
-Atributos: 
href="http://www.e-style.com.ar/resumen.html" → Define la dirección del enlace. Obligatorio.
type="text/html" → Indica el tipo de contenido al que apunta el enlace (en este caso, una página HTML). Opcional.
hreflang="es" → Especifica el idioma del documento enlazado (español). Opcional.
charset="utf-8" → Indica la codificación de caracteres del documento destino. Opcional.
rel="help" → Define la relación entre el documento actual y el destino; en este caso, el enlace lleva a una página de ayuda. Opcional.
-Obligatoriedad: El elemento <a> no es obligatorio dentro de un documento HTML, pero cuando se utiliza, el atributo href es esencial para definir 
la dirección del enlace. Los demás atributos (type, hreflang, charset, rel) son opcionales y se emplean para aportar información adicional sobre 
el recurso enlazado.
