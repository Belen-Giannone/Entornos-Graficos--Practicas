Ejercicio 2

Declaración de la primera regla:
p#normal {
font-family: arial,helvetica;
font-size: 11px;
font-weight: bold;
}
-Selector: p#normal. Selecciona los elementos <p> que tengan el atributo id con valor "normal".
-Declaraciones:
font-family: arial, helvetica -> establece la familia de fuente. Se usará Arial,
y si no esta disponible, Helvetica.
font-size: 11px -> establece el tamaño de la fuente en 11 pixeles.
font-weight: bold -> establece el texto en negrita.
-Aplicacion de la regla: 
<p id="normal">Este es un parrafo</p>
-Efecto: El texto del parrafo se mostrara con fuente Arial o Helvetica, tamaño de 11 pixeles y en negrita.

Declaración de la segunda regla:
*#destacado {
border-style: solid;
border-color: blue;
border-width: 2px;
}
-Selector: *#destacado. El selector universal * indica que puede seleccionar cualquier elemento que tenga el atributo id con el valor "destacado".
-Declaraciones:
boder-style: solid -> establece un borde de tipo solido.
boder-color: blue -> establece el color del borde en azul.
border.width: 2px -> establece el ancho del borde en 2 pixeles.
-Aplicaciones de la regla: 
<p id="destacado">Este es otro párrafo</p>
<table id="destacado"><tr><td>Esta es una tabla</td></tr></table>
-Efecto: El parrafo y la tabla tendran un borde azul, solido y de 2 pixeles.

Declaración de la tercera regla:
#distinto {
background-color: #9EC7EB;
color: red;
}
-Selector: #distinto. Selecciona el elemento que tenga el atributo id con valor "distinto".
 -Declaraciones:
 background-color: #9EC7EB -> establece el color de fondo.
 color: red -> establece el color del texto en rojo.
 -Aplicaicon de la regla: <p id="distinto">Este es el último párrafo</p>
 -Efecto: El parrafo tendra un fondo de colro #9EC7EB y el texto sera rojo.
